## ローカルでサーバーを立ち上げる

```
npm i -g pnpm

pnpm i
pnpm run dev
```

サーバーが起動したら、`http://localhost:5173` にアクセスしてください。

または [Vite extension for VS Code](https://marketplace.visualstudio.com/items?itemName=antfu.vite) を使用して、サイドバイサイドで編集できます。
