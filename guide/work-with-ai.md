# AI との連携

Slidev はマークダウンベースであるため、AI コーディングエージェントと非常に相性が良いです。

## Skills

Slidev は AI コーディングエージェント向けに公式の [スキル](https://code.claude.com/docs/en/skills) を提供しており、プレゼンテーションの作成を支援する際に Slidev の構文、機能、およびベストプラクティスを理解できるようにします。

### インストール

AI コーディングエージェントに Slidev スキルをインストールします:

```bash
npx add-skill slidevjs/slidev
```

スキルのソースコードは[ここ](https://github.com/slidevjs/slidev/tree/main/skills/slidev)にあります。

### プロンプト例

インストール後、エージェントにさまざまな Slidev タスクの支援を依頼できます:

```
TypeScript ジェネリクスに関する Slidev プレゼンテーションをコード例付きで作成してください
```
```

```
コード例を左側に、説明を右側に配置した 2 カラムのスライドを追加してください
```

```
クリックアニメーションを設定して、箇条書きを 1 つずつ表示させてください
```

```
スピーカーノート付きで PDF エクスポート用にプレゼンテーションを設定してください
```

### 含まれる内容

Slidev スキルは以下の知識を提供します:

- マークダウン構文、スライド区切り、フロントマター
- クリックアニメーションとトランジション
- コードのハイライト、Monaco エディタ、magic-move
- 図表 (Mermaid、PlantUML) と LaTeX 数式
- 組み込みレイアウトとコンポーネント
- エクスポートとホスティングのオプション
